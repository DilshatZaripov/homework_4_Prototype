ДЗ по курсе C# - "Порождающие шаблоны проектирования"

## Задание

0. Придумать и создать 3-4 класса, которые как минимум дважды наследуются и написать краткое описание текстом.
1. Создать свой дженерик интерфейс IMyCloneable для реализации шаблона "Прототип".
2. Сделать возможность клонирования объекта для каждого из этих классов, используя вызовы родительских конструкторов.
3. Составить тесты или написать программу для демонстрации функции клонирования.

5. Написать вывод: какие преимущества и недостатки у каждого из интерфейсов: IMyCloneable и ICloneable.

## Вывод: сравнение интерфейсов клонирования

В проекте реализованы 2 способа клонирования: кастомный `IMyCloneable<T>` и системный `System.ICloneable`

### Кастомный `IMyCloneable<T>`
**Преимущества:**
- Использование дженериков `<T>`, как гарант безопасности типизации и избавления от явного приведения типов
- Ковариантное возвращение значения `<out T>`, что исключает возникновения `InvalidCastException`

**Недостатки:**
- Другие фреймворки будут ожидать использования стандартного `System.IClonable`, поэтому необходимо реализовать и его, но при этом использовать метод из кастомного интерфейса

### Системный `System.ICloneable`
**Преимущества:**
- Стандартный интерфейс, который доступен "из коробки"

**Недостатки:**
- Возвращает `object`, из-за чего приходится использовать приведение типов, что, порой, не безопасно
- Не понятно требование: использовать глубокое копирование или поверхностное
